### Jean-Noël Schilling

**I build personal digital environments people can trust, at home and at work, with as little dependence as possible.**

Polymer engineer by training, self-taught developer. My work starts from three questions: who owns your knowledge, who decides what reaches it, and how can it save you time and space?

#### Where my code lives

My code lives on my own forge, [forge.lockilabs.com](https://forge.lockilabs.com), self-hosted. GitHub carries the mirrors: a project comes here when it is ready to be shown.

#### What I do

- **Sovereign by design.** A personal environment rebuilt piece by piece: cloud applications where a tool is genuinely useful, self-hosted where the risk is too high, every choice reconsidered, from the commercial chat to the browser.
- **AI agents that serve the decision, not replace it.** Self-hosted RAG and specialised agents, every action traced, the human always in the middle. Running daily across 17 projects.
- **Data engineering for industry.** ETL pipelines, Rust microservices, predictive and risk models for manufacturing, plastics and finance.
